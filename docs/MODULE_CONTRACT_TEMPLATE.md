# Module contract template

Use an actual module identifier and verified source references. Mark every unknown `UNVERIFIED`, absent feature `NOT_APPLICABLE`, and future recommendation `PROPOSED`.

## 1. Purpose & Scope

Responsibility, exclusions, technical owner, human owner.

## 2. File Structure

Existing files, classes, methods, dependencies, risk.

## 3. Execution Flow

Actual entry point → handler → authorization → service → storage; Mermaid.

## 4. Coding Standards

Legacy constraints, names, allowed and forbidden edits.

## 5. Component & Interface Contracts

Signatures, callers, inputs, outputs, validation and errors.

## 6. Adding or Modifying Features

Task scope, affected files, implementation steps, documentation.

## 7. Data Ownership & Integrity

Tables, sensitive columns, real versus logical constraints, invariants.

## 8. Testing & Preview

Positive, negative, permissions, concurrency, regression, UI, evidence.

## 9. API & Integration Contracts

Existing routes/actions, payload, auth, error semantics, integrations.

## 10. Administrative & Role Behavior

Current roles/caps, page behavior, no implicit grants.

## 11. Compatibility & Change History

Baseline, approved changes, version support and release status.
