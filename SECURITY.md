# Security reporting

See [SECURITY_POLICY.md](docs/SECURITY_POLICY.md). Report suspected vulnerabilities
privately to the repository owner through an established company channel or GitHub
Private Vulnerability Reporting if enabled. Do not open a public issue with secrets,
customer records, invoice tokens, receipts or reproduction credentials.

No runtime version has been penetration-tested by this governance work. The
source audit lists observed controls and unresolved risks; it is not a certificate.
